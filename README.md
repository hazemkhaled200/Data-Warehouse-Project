# Data-Warehouse-Project

## 📖 Project Overview
Building a data warehouse using SQL and applying ETL processes, data modeling, and data analytics

Key highlights:

Consolidates data from CRM and ERB sources into a single warehouse
Implements a Bronze / Silver / Gold layered architecture
Star schema with 1 fact table and 2 dimension tables
Reusable stored procedures for full-load ETL


## 🎯 Business Requirements

Objective: Consolidate sales data from ERP and CRM systems to enable analytical reporting and informed decision-making.

Specifications:

Data Sources: Import data from CRM and ERB source systems provided as CSV files
Data Quality: Cleanse and resolve data quality issues before analysis
Integration: Combine sources into one user-friendly data model
Scope: Latest dataset only; no historization required
Documentation: Provide clear documentation of the data model
